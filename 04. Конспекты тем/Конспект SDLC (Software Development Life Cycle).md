# SDLC (Software Development Life Cycle)
**Дата:** 05-10-2026
**Тема:**  [[SDLC]]
**Связи**: [[Конспект Waterfall (Водопадная модель)]]
## Ключевые идеи
- **SDLC (Software Development Life Cycle)** — структурированный процесс создания ПО от идеи до вывода из эксплуатации

- 7 базовых этапов: Planning → Requirements → Design → Implementation → Testing → Deployment → Maintenance

- **Правило 1:10:100:** ошибка в требованиях стоит 1₽, в дизайне — 10₽, в коде — 100₽, на тестировании — 1 000₽, на проде — 10 000₽

- SDLC не навязывает конкретную методологию — это **мета-процесс**, который можно реализовать через Waterfall, Agile, V-Model и др.

- Международные стандарты: **ISO/IEC/IEEE 12207**, **ISO/IEC/IEEE 15288**

- Российские стандарты: **ГОСТ Р ИСО/МЭК 12207-2010**, **ГОСТ Р 57193-2016**, **ГОСТ 34.601-90**

## Примеры
-  **Роль SA на каждом этапе:**

| Этап           | Что делает SA                       | Ключевые артефакты                    |
| -------------- | ----------------------------------- | ------------------------------------- |
| Planning       | Оценка осуществимости, анализ AS-IS | Feasibility report                    |
| Requirements   | Сбор и формализация требований      | User Stories, SRS                     |
| Design         | Проектирование API, БД, интеграций  | OpenAPI specs, ER-диаграммы, Sequence |
| Implementation | Поддержка разработчиков, уточнения  | ADR (Architecture Decision Records)   |
| Testing        | Помощь QA, участие в UAT            | Тест-кейсы, решения по багам          |
| Deployment     | Демо, обучение, релиз-ноты          | Release Notes, акт приёмки            |
| Maintenance    | Анализ инцидентов, улучшения        | RCA (Root Cause Analysis)             |
