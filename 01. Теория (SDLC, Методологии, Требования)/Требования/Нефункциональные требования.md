**Если функциональные требования (FR) отвечают на вопрос "ЧТО система делает?", то нефункциональные требования (NFR) отвечают на вопрос "КАК она это делает?".**

### 🔑 7 ключевых категорий NFR (ILURPS + UX)

| Категория                                  | Что описывает                         | Пример метрики                                 |
| ------------------------------------------ | ------------------------------------- | ---------------------------------------------- |
| **I** — Integrity (Надежность/Целостность) | Устойчивость к сбоям, восстановление  | MTBF (Mean Time Between Failures) > 1000 часов |
| **L** — Localization (Локализация)         | Языки, валюты, форматы дат            | Поддержка RU, EN, KZ; формат даты ДД.ММ.ГГГГ   |
| **U** — Usability (Удобство использования) | Время обучения, количество кликов     | 95% пользователей выполняют задачу за 3 клика  |
| **R** — Reliability (Доступность)          | Uptime системы                        | 99.9% (допускается 8.7 часов простоя в год)    |
| **P** — Performance (Производительность)   | Скорость отклика, нагрузка            | Время отклика API < 200 мс при 1000 RPS        |
| **S** — Security (Безопасность)            | Шифрование, аутентификация            | Соответствие ФЗ-152, шифрование TLS 1.2+       |
| **UX/A** — Accessibility (Доступность)     | Поддержка скринридеров, контрастность | Соответствие стандарту WCAG 2.1 AA             |

### 📐 Формула идеального NFR

```
[Категория NFR] + [Что измеряем] + [Числовое значение] + [Единица измерения] + [При каком условии]
```

### ✅ Хорошие примеры NFR:

- **NFR-P-01 (Performance):** Время отклика API `POST /cart/apply-promo` не должно превышать **200 мс** при нагрузке **до 500 RPS**.
- **NFR-R-01 (Reliability):** Система должна быть доступна **99.9%** времени (SLA), за исключением плановых технических работ по воскресеньям с 03:00 до 05:00 МСК.
- **NFR-S-01 (Security):** Промокоды должны передаваться по протоколу **HTTPS с TLS 1.2 или выше**, без логирования в открытом виде.

### ❌ Плохие примеры NFR:

- ❌ _"Система должна работать быстро"_ → Что такое "быстро"? 100 мс или 5 секунд?
- ❌ _"Система должна быть безопасной"_ → Как проверить безопасность? Какие стандарты?
- ❌ _"Система должна быть удобной"_ → Удобной для кого? По какой метрике?
